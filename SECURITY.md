# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not publish
potentially exploitable details in a public issue. If private reporting is unavailable, contact
the maintainers through GitHub before disclosing details publicly.

This project is experimental and is not a security service. Do not submit real private messages,
credentials, or personal data in public issues or pull requests.

## Supported versions

Only the latest version on the `main` branch is actively reviewed.
